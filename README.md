# ☢️ Осадок · Сектор Ноль

Объединённый проект во вселенной «Осадка». С главной страницы можно выбрать один из двух режимов.

| Папка | Что это |
|---|---|
| `index.html` | Главное меню с выбором режима |
| `osadok/` | **Осадок**: онлайн-выживание в Пустоши. Копия репозитория `Osadokk`, код не изменён |
| `sector/` | **Сектор Ноль**: одиночные текстовые вылазки в эпицентр, где выпал осадок |
| `assets/` | Логотип и иконка «Осадка» |
| `serve.ps1` | Мини-сервер для проверки на компьютере: `http://localhost:8765/` |

Оригинальный репозиторий `Osadokk` живёт отдельно. Если обновили «Осадок» там, скопируйте новые файлы в папку `osadok/`.

## Сектор Ноль: что внутри
- 11 локаций: от бункера «Клён» до корпуса «Полюс»
- Показатели как в «Осадке»: здоровье, еда, вода, радиация, опыт и уровни, крышки
- Обыск локаций, лут, артефакты в аномалиях
- Пошаговый бой с 7 видами противников, включая босса
- Оружие и броня с износом, пояс на 3 артефакта
- NPC: Кузьмич (торговля), Вера (ремонт), Док (лечение), Связист (сюжет)
- 6 заданий и финал
- Сохранение в браузере

## Где что править (Сектор Ноль)
| Что | Файл |
|---|---|
| Предметы, цены, урон | `sector/js/data.js` → `ITEMS` |
| Локации, выходы, лут | `sector/js/data.js` → `LOCATIONS` |
| Мутанты | `sector/js/data.js` → `MUTANTS` |
| NPC и задания | `sector/js/data.js` → `NPCS`, `QUESTS` |
| Правила (бой, радиация, еда, вода, опыт) | `sector/js/game.js` |
| Внешний вид | `sector/css/style.css` |

**Свои картинки локаций:** положите файл в `sector/img/` и добавьте в локацию строку `img: 'img/bunker.jpg',`.

## Публикация
GitHub → **Settings → Pages → Deploy from a branch → main / (root)**.
Адрес будет таким: `https://<логин>.github.io/<репозиторий>/`.
